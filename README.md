# Hotel ND Manor — Full Static Website

This package contains the full single-page hotel website, room videos, original gold ND logo, eight gallery photographs, SEO metadata, structured data, sitemap, robots.txt, 404 page and GitHub Pages workflow.

## Deploy to GitHub Pages
1. Upload the contents of this folder to the root of the intended website repository.
2. In GitHub, open Settings → Pages and select GitHub Actions as the build/deployment source.
3. The included `.github/workflows/pages.yml` deploys the static site.
4. Configure `ndmanor.com` and `www.ndmanor.com` DNS at your domain registrar and enable HTTPS in GitHub Pages after DNS verification.
5. After the domain is live, test `https://ndmanor.com/`, `https://ndmanor.com/robots.txt` and `https://ndmanor.com/sitemap.xml`, then add the domain property in Google Search Console and submit the sitemap.

## SEO note
SEO metadata, local business structured data, canonical tags, image alt text, internal links, and sitemap are included. Search ranking cannot be guaranteed; verify business details, maintain Google Business Profile, earn genuine reviews and local citations, and ensure the site is indexed.

## Booking links
Links to verified direct listings are included where available. Other platform cards should be treated as search links until a direct Hotel ND Manor listing is confirmed. This site does not process payments or confirm reservations.
